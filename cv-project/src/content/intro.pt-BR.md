# CV Builder

Monte um currículo simples em poucos passos: adicione seus dados, sua experiência profissional e sua formação, e veja tudo reunido em um só currículo.

## Como usar

1. **General information**: preencha nome, e-mail e telefone e clique em **Submit General Information**.
2. **Professional information**: adicione um emprego e clique em **Submit**. Clique em **Add** para cada emprego a mais. Quando terminar, clique em **Submit Professional Information**.
3. **Educational information**: adicione seus cursos do mesmo jeito e clique em **Submit educational information**.
4. Clique em **Done** para ver o currículo pronto. **Go Back** volta para os formulários, onde você pode editar qualquer seção.

Seus dados ficam só nesta aba do navegador. Recarregar a página apaga tudo, e nada é enviado para lugar nenhum.

## Sobre o projeto

Esta é a minha versão do projeto CV Application do [The Odin Project](https://www.theodinproject.com/), um currículo open source de desenvolvimento web. Construí o app para praticar React com código limpo e em padrão de produção, e ele vai além do que o enunciado original pede.

Escrevi todo o JavaScript e o JSX eu mesmo, sem código gerado por IA. O CSS foi escrito em grande parte por IA, já que o foco deste projeto é React, não design.
