# CV Builder

Build a simple CV in a few steps: add your details, your work experience and your education, then see it all together as one CV.

## How to use it

1. **General information**: enter your name, email and phone, then click **Submit General Information**.
2. **Professional information**: add a job and click **Submit**. Click **Add** for each extra job. When you're done, click **Submit Professional Information**.
3. **Educational information**: add your courses the same way, then click **Submit educational information**.
4. Click **Done** to see your finished CV. **Go Back** takes you back to the forms, where you can edit any section.

Your data stays only in this browser tab. Refreshing the page clears it, and nothing is sent anywhere.

## About this project

This is my version of the CV Application project from [The Odin Project](https://www.theodinproject.com/), an open-source web development curriculum. I built it to practice React with clean, production-style code, and it goes further than the original brief.

I wrote all of the JavaScript and JSX myself, with no AI-generated code. The CSS was mostly AI-written, since this project is about React, not design.
