# CV Builder

**English** | [Português](README.pt-BR.md)

A React app for building a CV: fill in your personal details, work experience and education, then view them together as a finished CV.

## About the project

[The Odin Project](https://www.theodinproject.com/) is an open-source web development curriculum. Its React course includes a [CV Application](https://www.theodinproject.com/lessons/node-path-react-new-cv-application) project, and this is my take on it. It goes further than the brief asks for, adding multiple entries per section, per-entry editing and deletion, and a separate CV preview.

My goal was to apply React the way it would be used in real work: small components, a single source of truth for state, logic shared instead of copied, and code that stays readable as it grows.

## Features

- **Three sections**: general information (name, email, phone), professional experience (company, position, dates) and education (institution, course, dates).
- **Add, edit and delete entries**: experience and education accept as many entries as you need.
- **Submit or edit each section**: submitting a section locks it, and you can unlock it again to make changes.
- **CV preview**: once all three sections are submitted, a **Done** button shows the full CV. **Go Back** returns to the forms and keeps your data.

## Tech stack

- [React 19](https://react.dev/)
- [Vite](https://vite.dev/) for the dev server and build
- [Oxlint](https://oxc.rs/docs/guide/usage/linter) for linting

## Getting started

You need [Node.js](https://nodejs.org/) installed.

```bash
git clone https://github.com/GabrielBiasolli/cv_application.git
cd cv_application/cv-project
npm install
npm run dev
```

Then open the URL Vite prints (usually http://localhost:5173).

| Command           | What it does                          |
| ----------------- | ------------------------------------- |
| `npm run dev`     | Starts the dev server with hot reload |
| `npm run build`   | Builds for production into `dist/`    |
| `npm run preview` | Serves the production build locally   |
| `npm run lint`    | Runs Oxlint                           |

## Project structure

```
cv-project/src/
├── App.jsx                     # Holds all CV state and switches between forms and preview
├── components/
│   ├── GeneralForm.jsx         # Name, email, phone
│   ├── ProfessionalForm.jsx    # Work experience entries
│   ├── EducationForm.jsx       # Education entries
│   └── RenderCV.jsx            # Read-only CV view
└── tools/
    └── tooling.jsx             # Shared list logic: add, show, edit, delete
```

All data lives in React state in `App.jsx` and is passed down to each section. The three sections share the same list logic from `tools/tooling.jsx`, and each one supplies its own form and display components.

## What I practiced

- Splitting a UI into focused components and passing data and callbacks through props
- Lifting state up so several components share one source of truth
- Controlled and uncontrolled form inputs
- Conditional rendering, and rendering lists with keys
- Reusing logic by passing components as props, so one piece of code handles three kinds of lists

## A note on AI

I wrote all of the JavaScript and JSX myself. I used research, including AI, to learn React syntax and common production patterns, but no application code was generated by AI. The exception is the CSS, which was mostly AI-written. It is a small part of the project, and the project is about React, not UI design.
